# UI style requirements:
- Modern mobile UI for a fitness/wellness app.
- Soft minimal design, light and calm.
- Light background (white with subtle green/mint tint).
- No dark mode for now.
- Card-based layout with rounded corners (16–24px).
- No heavy shadows; very subtle elevation or none.
- One primary accent color (soft green/mint) used only for primary actions.
- Neutral secondary colors (light gray for borders, muted text).
- Large readable typography, clear hierarchy:
  - Page title
  - Section title
  - Body text
- Inputs and buttons should look friendly, not sharp:
  - Rounded inputs
  - Comfortable spacing
- No decorative elements, no illustrations unless necessary.
- Focus on clarity and usability, not visual experiments.

## Date & Time formatting

- Target region: Russia.
- 24-hour time format only.
- AM/PM must never be used.
- Time: HH:mm.
- Date examples: "24 апр", "24 апреля 2024".
